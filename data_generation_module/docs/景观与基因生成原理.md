# 景观与基因生成原理

## 1. 物理动力学层（`graph_core.py`）

该层负责定义 Waddington 风格的势能景观，并计算细胞状态在景观中的漂移方向。

### 1.1 关键对象

- `GraphNode`：普通节点，定义局部势能深度与宽度。
- `CycleNode`：环形节点，额外包含 `radius` 与 `omega`，用于周期运动。
- `GraphEdge`：连接节点的通道，支持属性插值与停靠逻辑。
- `UniversalGraphSystem`：融合所有节点和边，给出全局势能与漂移场。

### 1.2 漂移组成

漂移项可理解为三部分叠加：

- 势能梯度驱动
- 非保守旋转项（如果存在）
- 边界约束项

## 2. 基因表达层（`synthesizer_gene.py`）

该层将低维坐标映射到基因表达，并在动力学模式下生成 `unspliced`、`spliced` 与真实 velocity。

### 2.1 核心机制

- 沿边或环进行投影，得到进度/相位。
- 用空间门控限制“靠近该路径时才表达”。
- 通过模块（`sigmoid`、`impulse`、`cycle`）组合表达模式。

### 2.2 动力学生成

`generate_kinetics(...)` 对每个细胞执行 ODE 积分，输出：

- `unspliced`
- `spliced`
- `velocity`（地面真值）
- `alpha`

并可叠加测序噪声（库大小扰动、dropout 等）。

## 3. 两层如何衔接

1. 先在拓扑层生成轨迹 `Z`。
2. 再在基因层对 `Z` 做投影 + 门控 + ODE 积分。
3. 最终得到可用于 RNA velocity 基准测试的数据对象。
