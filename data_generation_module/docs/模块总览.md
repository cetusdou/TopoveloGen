# 模块总览

## 当前结构

- `graph_core.py`：定义 `GraphNode`/`CycleNode`/`GraphEdge`/`UniversalGraphSystem`。
- `utils.py`：提供 `GraphSimulator` 与 `GraphVisualizer`。
- `synthesizer_gene.py`：实现基因模块定义与 `spliced/unspliced/velocity` 生成。
- `presets.py`：统一维护拓扑预设和默认基因模块预设。
- `gene_config_loader.py` + `generate_gene_config.py`：配置驱动的基因模块生成与加载。

## 推荐使用路径

1. 用 `build_topology(...)` 构建拓扑。
2. 用 `GraphSimulator.run(...)` 模拟轨迹。
3. 初始化 `GeneSynthesizer(...)`。
4. 用 `attach_default_gene_modules(...)` 挂载默认模块。
5. 用 `generate_kinetics(...)` 生成动力学数据。

## 维护规范

- 拓扑构建逻辑只放在 `presets.py`。
- 默认基因模块装配逻辑只放在 `presets.py`。
- 外部脚本禁止重复定义同一套节点/边/模块装配代码，应直接调用预设接口。
