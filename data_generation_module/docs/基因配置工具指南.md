# 基因配置工具指南

`generate_gene_config.py` 用于生成可被 `GeneSynthesizer.load_from_config()` 读取的 YAML 配置。

## 快速开始

生成示例配置：

```bash
python data_generation_module/generate_gene_config.py --output config.yaml --example
```

## 常用命令

添加 Cycle 基因：

```bash
python data_generation_module/generate_gene_config.py --output config.yaml \
  --cycle-node Cycle --cycle-n 50
```

添加 Edge 基因：

```bash
python data_generation_module/generate_gene_config.py --output config.yaml \
  --edge-idx 0 --edge-n 30 --edge-pattern sigmoid \
  --edge-idx 1 --edge-n 30 --edge-pattern sigmoid
```

## 关键参数

- `--cycle-node` / `--cycle-n`：Cycle 基因所属节点与数量
- `--edge-idx` / `--edge-n` / `--edge-pattern`：Edge 基因定义
- `--edge-reverse`：是否反向表达趋势
- `--edge-sticky`：是否启用 sticky 模式
- `--output`：输出 YAML 路径
- `--seed`：随机种子

## 使用配置文件

```python
from data_generation_module import GeneSynthesizer

synth = GeneSynthesizer(system=system, n_genes_total=200)
gene_name_to_idx = synth.load_from_config("config.yaml")
```

## 注意事项

1. 配置中的基因总数不能超过 `n_genes_total`。
2. `edge_idx` 必须与当前拓扑中的边索引一致。
3. `node_id` 必须与当前拓扑节点名称一致。
